## MapReduce Word Frequency Analysis

This project demonstrates the use of the MapReduce programming model in Python to analyze large-scale textual data.

The dataset consists of multiple news articles containing topics such as technology, climate change, cybersecurity, and global events. Using MapReduce, the project processes the text data to identify the most frequently occurring words and extract meaningful insights from unstructured data.

### Project Objectives

* Process large text datasets efficiently
* Extract word frequency using MapReduce
* Demonstrate distributed data processing concepts
* Analyze unstructured textual data

### Technologies Used

* Python 3
* MapReduce (MRJob)
* Text Dataset (.txt)

### How It Works

* **Map Phase:** Extracts words from the text and emits key-value pairs (word, count)
* **Reduce Phase:** Aggregates counts to calculate total word frequency

This project demonstrates core data engineering concepts including scalable processing, distributed computation, and large dataset analysis using Python.
